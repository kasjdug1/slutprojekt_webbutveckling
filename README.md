# Target Tasty (slutprojekt webbutveckling)

En statisk webbplats (HTML/CSS/JS) för Target Tasty.

## Sidor (tydliga filnamn: gemener, bindestreck, ASCII)

| Fil | Innehåll |
|-----|-----------|
| `index.html` | Startsida |
| `om-oss.html` | Om oss |
| `vanliga-fragor.html` | Vanliga frågor (FAQ) |
| `recept-och-maltider.html` | Recept och måltidslösningar (översikt) |
| `recept-kalorisnalt.html` | Kalorisnåla recept |
| `recept-kalorioverskott.html` | Kaloriöverskott |
| `recept-detalj.html` | Detaljerat exempelrecept |
| `recensioner.html` | Recensioner |
| `kontakta-oss.html` | Kontakt |
| `sociala-medier.html` | Sociala medier |
| `kundvagn.html` | Kundvagn |
| `kassa.html` | Kassa |
| `order-bekraftelse.html` | Orderbekräftelse (demo) |
| `nyhetsbrev.html` | Nyhetsbrev (demo) |
| `logga-in.html` | Inloggning |
| `skapa-konto.html` | Registrering |
| `anvandarprofil.html` | Inloggad profil |

## Resurser

- `css/stilmall.css` – gemensam stilmall
- `js/inloggning.js` – inloggning och registrering (`localStorage`)
- `js/profil.js` – profilsida
- `js/recensioner.js` – recensionslista
- `images/` – lägg egna bildfiler här; i HTML skriver du t.ex. `src="images/min-bild.jpg"` på respektive `<img>`

## Köra projektet

Öppna `index.html` i webbläsaren.

## Notering

Inloggning och recensioner sparas i `localStorage` i webbläsaren (endast demo, ingen server).
