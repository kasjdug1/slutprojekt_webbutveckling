# Target Tasty (slutprojekt webbutveckling)

En enkel statisk webbplats (HTML/CSS/JS) som visar Target Tasty och dess funktioner:
- Startsida
- Om oss
- Vanliga frågor
- Recept och måltidslösningar (inkl. undersidor)
- Recensioner
- Användarprofil (inloggning lokalt i webbläsaren)
- Nyhetsbrev
- Kundvagn, kassa och orderbekräftelse (skelett)

## Köra projektet
- Öppna `index.html` i webbläsaren.

## Notering
Inloggning och sparad data ligger i `localStorage` (endast demo).
